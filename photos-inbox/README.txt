# 照片替换投放箱（照片即放即换）

把想替换的新照片放进本文件夹，**文件名叫成网站上那张照片的名字**，然后运行：

```
npm run photos:swap
```

比如你想替换「老街的寻常午后」（网站照片名 street-01），就把新照片命名为 `street-01.jpg`（或
`.png` / `.webp`）放进这里，运行命令后网站上的那一张就被换成你的新照片了（标题、图注、分组不变）。

## 想增加新照片（不是替换）？

替换之外要「新增一张」时，请编辑 `scripts/photo_config.json` 里的分组列表并运行
`npm run photos`（新增照片需要指定 D 盘原路径、标题、图注与版面大小）。
